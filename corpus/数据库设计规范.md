
# 数据库设计规范

## 一、命名规范

### 1.1 表名
- 使用小写字母和下划线：user_profiles
- 使用复数形式：users、orders
- 避免保留字：❌ order ✅ orders

### 1.2 字段名
- 使用小写字母和下划线：user_name
- 主键统一命名：id
- 外键命名：表名_id，如 user_id
- 时间字段：created_at、updated_at

### 1.3 索引名
- 普通索引：idx_字段名
- 唯一索引：uniq_字段名
- 联合索引：idx_字段1_字段2

## 二、字段类型

| 类型 | 推荐 | 说明 |
|:---|:---|:---|
| 主键 | BIGINT UNSIGNED | 自增 |
| 字符串 | VARCHAR(255) | 短文本 |
| 长文本 | TEXT | 超过 255 字符 |
| 金额 | DECIMAL(10,2) | 禁止用 FLOAT |
| 时间 | DATETIME | 精确到秒 |
| 布尔 | TINYINT(1) | 0/1 |

## 三、索引规范

- 每个表必须有主键
- 外键字段必须建索引
- 频繁查询的字段建索引
- 联合索引遵循最左前缀原则
- 单表索引不超过 5 个

## 四、SQL 规范

- 禁止 SELECT *，必须指定字段
- 禁止在 WHERE 中对字段做函数运算
- 禁止大表 JOIN 大表
- 批量插入每批不超过 1000 条
- 禁止使用存储过程

## 五、分库分表

- 单表超过 1000 万行考虑分表
- 分表键选择查询最频繁的字段
- 分表后需保证全局唯一 ID
