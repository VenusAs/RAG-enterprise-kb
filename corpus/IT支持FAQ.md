
    # IT支持FAQ

## 账号相关

### Q1：忘记密码怎么办？
A：企业微信 → IT服务 → 密码重置，或联系 IT 部门。

### Q2：账号被锁定怎么办？
A：连续 5 次密码错误会锁定，30 分钟后自动解锁。

### Q3：怎么申请新账号？
A：企业微信 → IT服务 → 账号申请，需主管审批。

## 设备相关

### Q4：电脑坏了怎么办？
A：企业微信 → IT服务 → 设备报修，IT 部门 2 小时内响应。

### Q5：怎么申请新电脑？
A：企业微信 → IT服务 → 设备申请，需部门总监审批。

### Q6：设备丢失怎么办？
A：立即联系 IT 部门，远程锁定设备，并报警。

## 网络相关

### Q7：VPN 怎么连？
A：下载 VPN 客户端，服务器地址咨询 IT 部门，用企业微信扫码登录。

### Q8：网络很慢怎么办？
A：先重启路由器，如仍慢，联系 IT 部门。

### Q9：怎么访问内网？
A：需连 VPN，或使用公司 WiFi。

## 软件相关

### Q10：正版软件怎么申请？
A：企业微信 → IT服务 → 软件申请，需主管审批。

### Q11：能装盗版软件吗？
A：禁止安装盗版软件，违者按公司规定处理。

### Q12：怎么申请 GitHub 账号？
A：企业微信 → IT服务 → 账号申请，选择 GitHub。
