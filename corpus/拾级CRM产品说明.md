
    # 拾级CRM 产品说明 v3.1

## 一、产品定位
面向中小企业的客户关系管理系统，帮助企业高效管理客户、提升成交率。

## 二、目标客户
- 员工规模：10-200 人
- 行业：服务业、零售业、B2B 销售
- 典型场景：销售团队管理、客户跟进、数据分析

## 三、核心功能

### 3.1 客户管理
- 客户录入：手动录入、批量导入、API 对接
- 客户分类：按行业、规模、来源分类
- 跟进记录：记录每次沟通内容
- 客户画像：自动生成客户标签

### 3.2 销售漏斗
- 可视化销售阶段：线索→商机→报价→成交
- 阶段转化率分析
- 销售预测

### 3.3 数据分析
- 客户画像分析
- 成交预测
- 销售排行榜
- 趋势分析

### 3.4 集成能力
- 企业微信：消息推送、客户同步
- 钉钉：审批、考勤集成
- 邮件：自动发送跟进邮件
- API：开放 RESTful API

## 四、技术架构
- 前端：Vue 3 + Element Plus
- 后端：Spring Boot + MySQL + Redis
- 部署：Docker + Kubernetes
- 云服务：阿里云

## 六、常见问题

### Q：支持多少用户？
A：基础版最多 10 用户，专业版最多 50 用户，企业版不限。

### Q：数据存储在哪里？
A：SaaS 版存储在阿里云，企业版支持私有化部署。

### Q：支持二次开发吗？
A：支持，提供开放 API 和 SDK。
