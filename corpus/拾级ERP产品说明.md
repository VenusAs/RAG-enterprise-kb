
    # 拾级ERP 产品说明 v2.5

## 一、产品定位
面向制造业的企业资源计划系统，帮助企业实现生产、库存、财务一体化管理。

## 二、目标客户
- 员工规模：50-500 人
- 行业：制造业、加工业
- 典型场景：生产计划、库存管理、成本核算

## 三、核心功能

### 3.1 生产管理
- 生产计划：根据订单自动生成
- 物料需求：MRP 运算
- 生产排程：甘特图可视化
- 质量管理：来料检验、过程检验、成品检验

### 3.2 库存管理
- 实时库存：多仓库、多批次
- 库存预警：低于安全库存自动提醒
- 出入库管理：扫码出入库
- 库存盘点：定期盘点、差异分析

### 3.3 财务管理
- 应收应付
- 成本核算
- 财务报表
- 预算管理

### 3.4 供应链管理
- 供应商管理
- 采购管理
- 物流跟踪

## 四、技术架构
- 前端：React + Ant Design
- 后端：.NET Core + SQL Server
- 部署：私有化部署为主
- 硬件：支持本地服务器

## 六、常见问题

### Q：支持多少用户？
A：不限用户数，按并发数计费。

### Q：实施周期多长？
A：标准版 1-2 个月，专业版 3-6 个月。

### Q：支持多工厂吗？
A：支持，可管理多个工厂和仓库。
