
    # 开发与测试流程

## 一、开发流程

### 1.1 任务领取
- 从 Jira 领取任务
- 确认需求理解无误
- 评估工作量，超过 3 天需拆分

### 1.2 开发
- 从 develop 切出 feature 分支
- 遵循代码规范
- 每完成一个小功能就提交
- 提交前运行单元测试

### 1.3 自测
- 开发完成后本地自测
- 覆盖正常流程和边界情况
- 自测通过后提交 MR

## 二、测试流程

### 2.1 提测
- 开发提交 MR 后，通知测试
- 提供测试环境和测试数据
- 提供变更说明和影响范围

### 2.2 测试
- 测试工程师执行测试用例
- 覆盖功能、性能、兼容性
- 发现 bug 提交 Jira，指派给开发

### 2.3 回归测试
- bug 修复后重新测试
- 确保修复没引入新问题
- 回归通过后关闭 bug

## 三、质量门禁

| 指标 | 要求 |
|:---|:---|
| 单元测试覆盖率 | ≥ 70% |
| 严重 bug | 0 |
| 一般 bug | ≤ 3 |
| 性能 | 响应时间 ≤ 500ms |

## 四、禁止事项

- 禁止未自测就提测
- 禁止带严重 bug 上线
- 禁止跳过回归测试
