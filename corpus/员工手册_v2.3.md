
# 拾级科技员工手册 v2.3

## 第一章 考勤与休假

### 1.1 工作时间
公司实行弹性工作制，核心工作时间为 10:00-16:00。
员工每天需保证 8 小时工作时间，上下班需在企业微信打卡。
迟到超过 30 分钟需向直属主管报备。

### 1.2 年假制度
- 入职满 1 年：5 天年假
- 入职满 3 年：10 天年假
- 入职满 5 年：15 天年假
- 入职满 10 年：20 天年假
- 年假需提前 3 个工作日申请，经直属主管审批。
- 年假当年有效，不累积到次年，特殊情况需总经理审批。
- 年假可分次使用，最小单位为半天。

### 1.3 病假制度
- 病假需提供医院证明。
- 每月病假不超过 2 天不扣工资。
- 超过 2 天的部分，按日工资的 60% 发放。
- 连续病假超过 7 天，需提供三甲医院证明。
- 病假期间需保持通讯畅通，紧急工作可远程处理。

### 1.4 事假制度
- 事假需提前 1 个工作日申请。
- 事假按日工资全额扣除。
- 每月事假不超过 3 天。
- 事假超过 3 天需总经理审批。

### 1.5 婚假与产假
- 婚假：3 天，晚婚（男满 25 岁，女满 23 岁）增加 7 天。
- 产假：158 天（含法定 98 天 + 地方奖励 60 天）。
- 陪产假：15 天。
- 产假期间工资按正常发放。

## 第二章 薪酬与报销

### 2.1 发薪日
每月 15 日发放上月工资，遇节假日提前至最近工作日。
工资条通过企业微信推送，如有疑问需在 5 个工作日内提出。

### 2.2 差旅报销
- 市内交通：凭发票实报实销，单次不超过 100 元。
- 出差住宿：一线城市不超过 500 元/晚，二线城市不超过 350 元/晚，其他城市不超过 250 元/晚。
- 出差补贴：100 元/天。
- 报销需在出差结束后 15 个工作日内提交。
- 超过 15 个工作日未提交，需部门总监审批。

### 2.3 团建经费
每人每季度 200 元团建经费，由部门统一组织使用。
团建经费不可折现，不可累积到下季度。

### 2.4 加班补贴
- 工作日加班：1.5 倍工资
- 周末加班：2 倍工资
- 法定节假日加班：3 倍工资
- 加班需提前申请，经主管审批。

## 第三章 技术规范

### 3.1 代码提交规范
- 所有代码必须经过 Code Review 才能合并到主分支。
- Commit Message 格式：`<type>: <description>`
  - type 可选：feat / fix / docs / style / refactor / test / chore
- 每次提交不超过 500 行代码。
- 提交前必须运行单元测试，确保通过。

### 3.2 分支管理
- main：生产分支，只接受 merge request
- develop：开发分支，日常开发在此
- feature/xxx：功能分支，从 develop 切出
- hotfix/xxx：紧急修复分支，从 main 切出
- release/xxx：发布分支，从 develop 切出

### 3.3 部署流程
1. 开发完成，提交 MR 到 develop
2. Code Review 通过后合并
3. 测试环境验证
4. 提交 MR 到 main
5. 运维手动触发部署

## 第四章 产品说明

### 4.1 产品矩阵
- **拾级CRM**：面向中小企业的客户关系管理系统
- **拾级ERP**：面向制造业的企业资源计划系统
- **拾级AI**：面向开发者的 AI 应用开发平台

### 4.2 拾级CRM 核心功能
- 客户管理：录入、分类、跟进记录
- 销售漏斗：可视化销售阶段
- 数据分析：客户画像、成交预测
- 集成能力：支持企业微信、钉钉

### 4.3 拾级AI 核心功能
- 模型接入：支持 DeepSeek、通义千问、OpenAI
- RAG 引擎：内置文档检索增强生成
- Agent 框架：支持工具调用和多轮对话
- 部署方式：SaaS 和私有化部署

## 第五章 常见问题

### 5.1 如何申请年假？
登录企业微信 → 审批 → 请假申请 → 选择年假 → 填写日期 → 提交主管审批。

### 5.2 忘记打卡怎么办？
在企业微信 → 考勤 → 补卡申请，每月最多补卡 3 次。

### 5.3 如何申请设备？
在企业微信 → IT服务 → 设备申请，填写设备类型和用途，IT 部门 3 个工作日内处理。

### 5.4 公司 WiFi 密码是什么？
办公室 WiFi：ShijiTech-5G，密码请咨询 IT 部门（出于安全考虑不公开）。
